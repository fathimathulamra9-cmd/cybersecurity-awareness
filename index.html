How to Recognize Phishing

Watch for these warning signs before clicking a link.

  • Unexpected messages asking for passwords or bank details.
  • Links that use misspelled or unfamiliar website addresses.
  • Messages creating urgency or threatening account closure.
  • Unexpected attachments or requests for verification codes.

Safety tip: Visit the official website directly instead of following suspicious links.

✓ Use long, unique passwords for different accounts.

✓ Use a reputable password manager.

✓ Turn on multi-factor authentication when available.

✓ Never share one-time verification codes with others.
